# ATC trenažér Ruzyně

Výcviková hra řízení letového provozu pro letiště Praha Ruzyně (LKPR): pracoviště APP a TWR.
Statická webová aplikace pro iPad (Safari), hostovaná přes GitHub Pages.

- `index.html` – celá aplikace
- `voices/` – hlasové balíčky pilotů (MP3 sprite + index)

Data jsou zjednodušená pro výcvikovou hru a nejsou určena k navigaci.
